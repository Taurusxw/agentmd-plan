# AGENTS.md 28.1.0 正式发布补丁说明

本次正式版本动作：`27.13.0 -> 28.1.0`，按最高影响属于 `MAJOR`。全局规则、项目 `VERSION`、Git tag 和 GitHub Release 统一使用 `v28.1.0`。

## 变更原因

原规则会把有来源的普通调研默认送入 Seer Knowledge，且其他项目曾把局部治理建议直接写入全局主规则，改变所有后续对话。新版同时收紧持久化授权和全局治理所有权。

## 修改内容

1. 截图、文档、链接和普通调研默认只分析，不调用 `seer-capture`；Knowledge/Book 写入必须针对当次明确材料和目标授权。
2. 持久化授权不得从其他对话、相邻任务、数量目标或平台流程继承。
3. 全局主 `AGENTS.md`、同步副本及 `seer-codex-rules` 源码和安装副本只允许在 `agentmd-plan` 专有项目内修改。
4. Owner Context Gate 同时要求当前工作区包含正式项目、最近项目规则声明所有权、当前任务明确针对治理系统。
5. 其他项目和对话一律进入 report-only 模式，只能生成包含证据、建议差异、版本影响、跨项目风险、验证和回退的报告供用户转交。
6. 禁止通过同步脚本、安装器、恢复任务、自动化、其他 Skill 或子 Agent 间接绕过所有权门禁。
7. guardrail 增加全局锚点、必需 reference 和测试，确保门禁不会在后续精简中静默丢失。

## 版本依据

相对于正式版 `27.13.0`，默认持久化行为和跨项目治理写权限均发生不兼容变化，因此正式发布使用 `MAJOR` 跳升后的 `28.1.0`。

## 状态边界

- live 全局、Downloads 副本和正式 artifact 使用 `28.1.0` 并保持字节一致。
- 项目、Codex 和 Skills Manager 的 `seer-codex-rules` 树保持一致。
- 本次 Git 只纳入 `28.1.0`，不提交、不打 tag、不发布中间 `28.0.0` 候选。
